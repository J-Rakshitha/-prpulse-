# Feature catalogue

Generated by `src/features/build.py`. Training uses pandas + scikit-learn only.

## Point-in-time decisions (size / text)

| Field | Decision |
| --- | --- |
| `additions` / `deletions` / `changed_files` / `commits` | **Blocked** (live PR object). |
| `title` / `body` / `labels_at_collection` | **Blocked** (editable after open). |
| `additions_approx` / path flags / `draft` | Computed into parquet for analysis but **excluded from model matrices** after leakage ablation (collection-time `pr_files` can include later pushes). |
| `commits_at_open` | `pr_commits` with `committed_at` null or `<= created_at` — **used in models**. |
